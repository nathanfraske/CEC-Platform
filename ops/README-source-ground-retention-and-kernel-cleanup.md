# Source-exact Ground retention and obsolete local return cleanup

These experimental agent-side tools extend immutable receiving code. They do
not change current budgets, factory profiles, library part selections, release
gates or the active Beta schematics. No board name, refdes or coordinate selects
a geometric exception.

## Fully retained stationary forest

`cec_fully_retained_ground_forest` recognizes the previously unhandled case in
which every Ground edge in a moving-cell fork remains needed by stationary
Source terminals. It proves literal Source paths to unchanged qualified roots,
removes that entire fork from reconstruction, and keeps all its native geometry.
The old partial-retention behavior is preserved. Source incident endpoints are
tested at Source geometry; only positively retained edges stay there. Other
temporary projected edges are restored even on refusal. The compiler may still
own an edge through another separately checked obligation; local retention is
not a blanket claim that the composite cell cuts no Ground.

`cec_retained_forest_macro` compiles a private namespace of the original macro,
compiler and escape planner; it does not monkey-patch their shared modules.
Every actual Source port obligation and independent saved-board gate remains.

## Negative stationary-copper filter

`cec_static_foreign_column_filter` caches native foreign copper for explicitly
identified moving footprints. A positive collision can reject a proposal early.
No collision, an exception, or an omitted moving pad is never permission to
construct: full native columns, actual projected pads, holes, zones, factory
process and current rules must still pass. This is a rejection accelerator,
not a clearance waiver or a global no-route proof.

## Obsolete generated local returns

`cec_manufacturer_ground_kernel_retirement` retains the old two-land capacitor
rule and permits a uniquely identified manufacturer `ground` or `power_return`
pin of a non-converter. The existing selected-package role catalog supplies
this authority. Unknown devices, address straps, duplicate pins and converters
with output/switch/feedback roles are refused. This does not assert that every
MCU, diode or resistor has a model or that all nearby old vias are redundant.

The original actual-geometry rules remain mandatory: one Ground land, one
unchanged qualified fully-in-pad root, a small generated obsolete barrel, a
bounded outer-layer kernel, no shared land/barrel/inner/foreign departure or
surface-zone contact, and real saved copper bridging both reference planes.
Subtraction is rederived independently, all surviving native partitions and
all known Ground returns must be preserved, and the saved child is separately
checked. Ordinary mesh/stitch deletion, new holes or invented current ratings
are not authorized.

The build-time structural search can find already-obsolete kernels even when
they have no DRC error. It commits one independently received step at a time,
re-inventories each changed Source, has an explicit accepted-step limit, and
retains earlier accepted progress after a later refusal. A native-only baseline
for the next search is expressly not a Full50/current/thermal/fabrication grade.
The whole-parent receiver independently replays all steps and the end-to-end
current, clipped-Kelvin, field, Ground, native DRC and craft boundaries.

The tests cover rotations, both outer faces, package roles, exact cuts, real
reference-plane contacts, shared-departure refusal and old-capacitor parity.
Synthetic geometry is not a hardware current, thermal or manufacturing rating.
