# Source-owned control finishing and actual-face kernel protection

Thin tracks on an inner signal face must not be classified from the net name
alone. `cec_actual_face_supply_kernel` rederives actual current/factory floors
on positively specified non-reference source faces. Preferred routing width
is not a physical current floor. New power bridges still require the original
whole-current outer-face floor; full-width conductors, attached pads, current
barrel interfaces and saved-pour contacts are protected. The existing power
capture guard remains mandatory and refuses any positively typed control leaf.

That guard correctly refuses the ATX inner pickup: it is part of a TLV755
manufacturer-proved tied-enable leaf, not the 3 A load path. The kernel trial
is a refusal, not a power repair, and no new numeric control load is assumed.

`cec_owned_control_span_finishing` is separate authority for a bounded span
already wholly owned by one positive original manufacturer-control proof.
The original classifier must re-own exactly source-minus-cut-plus-new native
material after saving, with the same enable pad, manufacturer/package and
original input capture. Width, process/class floor, original barrel geometry,
all other objects, current budgets and rules stay literal. New loops, spurs,
loads, ambiguous ownership and altered input captures refuse construction.

Existing barrel centres are search targets, not permission to run a thin
control segment into another retained current stem. A finite landing menu may
instead contact the unchanged annular copper. A bounding box or centre-point
coincidence is insufficient: each actual native incoming lower-bound capsule
must intersect the lower-bound barrel land after subtracting the real drill's
upper bound. Saved control ownership and native connectivity must independently
pass. No barrel/current/thermal qualification follows from this geometric proof.

The source-bound driver preflights exact typed ownership before funding saved
candidates and native checks. It does not repeatedly fund candidates which
the control classifier already refuses. Whole native DRC/custom-rule,
current, field, clipped-Kelvin, Ground-return, pair/reference, legend, dimensions
and matched-stack receivers still decide adoption. Immutable controls and
fabrication/release gates are unchanged. Synthetic fixture loads are not
hardware design-budget changes.
