# Retained consumer actual-floor reconstruction

`cec_retained_consumer_floor_repair.py` repairs an existing, positively proved
single-consumer island. It does not make an old thin trace acceptable or
change an allocation. The original shared rail ceiling, single real source
tap, selected package, complete consumer/capacitor/monitor island and margin
must be independently rederived from saved native topology.

Only one ungrouped outer-face path of at most eight plain, uniform-process
tracks is owned. Every original stroke must actually be below its derived
floor. Replacement copper stays on that face, uses the complete actual
floor including project/process minima, keeps the same end ports and every
old native contact web, and uses only exact 0/45-degree path turns. An
explicit finite exact-guard native search can propose the path; an agent's
coordinates are not authority. No part, barrel, allocation group, priority
bus, source budget, rule or other geometry may change.

The saved receiver reconstructs the entire source subtraction/replacement
and Ground refill, re-proves the same consumer and tap, checks every incoming
floor, preserves every surviving native partition and old full-width
allocated terminal join, and separately checks actual drilled terminals and
whole-board current-debt nonregression. It grants no barrel/thermal rating,
does not qualify remaining inherited debt, and cannot substitute for full
native DRC, clipped Kelvin, fields, pair/reference, Ground-return, dimensions,
stack and release checks. The older same-width retained-island owner and
all existing fabrication gates are unchanged.
