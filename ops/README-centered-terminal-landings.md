# Source-centered native power-terminal frames

`cec_centered_terminal_landing.py` addresses visible rounded power-terminal
silhouettes that an authored-outline/capsule-cover score can miss. It derives
eight symmetric 0/45 support planes from the actual unchanged barrel and any
literal contacting track widths, never from a board name, reference number or
hard-coded placement. The visual work domain includes existing 0.9 mm barrels;
the former 1 mm discovery work floor was not a design or manufacturing rule.

Only a registered, contacting, source-owned solid keeper on a non-reference
face of a known source power domain can change. The process, native tracks,
barrels, pads, fields, rules, pinouts, original fill records and every Ground
sheet stay literal. Fresh native fill is confined to the measured frame,
clipped against stronger same-net voids and retained only with actual Source
anchors. It cannot be fictional renderer/FEM copper or new ampacity credit.

The saved native union must show real added visible material and at least a
twofold reduction in the longest exposed curved perimeter run at the unchanged
source feature scale. This is an aesthetic interest metric, not a manufacturing
or material-loss tolerance. Raw noncanonical filled edges remain disclosed,
including native Boolean endpoint quantization. No track heading tolerance or
geometry snapping is introduced. Every authored new profile is literal 0/45.

Use `build/root_try_centered_terminal_landings_20261020.py` with an exact Source,
current grade and source-bound actual-terminal inventory. It tries a finite
portfolio of at most four distinct keeper repairs per candidate, requires exact
saved native reconstruction and full native DRC, and does not select a release.
Run `root_receive_centered_terminal_chain_20261020.py`, the independent full
grade, actual pair/reference/stack checks, and before/after native image review
before choosing a candidate. The whole-parent current, clipped Kelvin and
ground-return gates are unchanged. All retained controls must stay byte-exact.

This operator does not claim to remove every legacy tab, skewed field, pad toe,
or joined-boundary defect. Large Source features outside the terminal frame
remain a separate composed-boundary repair, not permission to widen the frame
until a score happens to pass. Zero opens and a local visual improvement are
not fabrication qualification.
