# Terminal-shadowed stubs and keeper contours

A pour rebuild can faithfully reproduce an ugly tab when an old short track
still generates that tab. Merely covering its via with a chamfered frame does
not retire the old trace or the keeper's historical excess.

`cec_terminal_shadow_keeper_finish.py` discovers short, actual same-face trace
axes entirely inside a real plated land projection, with exactly one surviving
literal endpoint junction. This is only a finite scheduling condition, not
permission to delete a load, a contact, rated copper, or an unknown branch.

The typed owner rederives the unchanged current authority and actual face floor.
It inventories every contained keeper stroke and requires all retained strokes
to keep their full Source widths. The new contour is the connected cardinal/45
union of those actual capsules and the incumbent source-centered via frames;
it cannot expand the original authored keeper. Every original surviving
keeper-to-track/pad/barrel contact is retained as literal positive native
material inside that derived contour. A port outside it causes refusal rather
than an invented bridge, narrowed neck, larger slab, or new current-sharing
assumption. Stronger same-net voids remain protected.

Construction compiles only the explicitly owned zone, preserving its settings,
UUID and lock. It neither refills Ground nor edits other owners. Independent
saved-source reconstruction, exact non-owned objects, all surviving native
partitions, full retained capsules and actual visible material removal must
pass. Native filled-edge quantization is disclosed; it does not relax any
track-heading, contact-material, width or clearance rule.

`root_run_terminal_shadow_pass_20261020.py` runs finite discovered cohorts and
keeps the last genuinely received child. Intermediate native-only intake checks
the actual report, source files and hashes and never claims a whole-board grade.
Every final phase must still pass `root_receive_terminal_shadow_chain_20261020.py`
with the original whole-parent current, field, Ground-return, clipped-Kelvin,
native DRC and metadata gates, followed by actual layer/contour/stack review.

No board, reference designator, coordinate exception, new hardware budget,
parallel-current credit, barrel rating or fabrication release is encoded.
Synthetic rotated/mirrored fixtures verify geometry and policy only; real-board
receipts stay tied to their exact saved sources and code. A no-progress or
contact-protection refusal is not an all-contours-clean or global no-path proof.
