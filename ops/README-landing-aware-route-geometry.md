# Landing-aware route geometry

The default ordinary half-leg miter limit is unchanged. A short old segment
can prevent a visibly full-width miter even when its remaining stub could sit
entirely inside an existing pad or via land. The new read-only geometry helper
may extend that search bound only after integer-native polygon subtraction
proves the **entire remaining capsule** lies inside a real retained same-face,
same-net landing silhouette. A bounding box, opposite face or via-centre
coincidence is insufficient. This is an occupancy witness, not plated contact
or current qualification. The original contact-web receiver remains separate.

`cec_landing_consumer_miter` is the typed owner: every cut must already belong
to one independently proved native consumer allocation, with the actual part,
pins, full output-load allowance, closed monitor loads, aggregate rail budget
and single physical tap unchanged. The source width, face, process and lock
policy are literal. New geometry retains both ports, clears every native
foreign obstacle, cannot create a new enclosed copper void, and preserves all
native contact webs. Saved receiving reconstructs the exact source delta and
reruns the original consumer-group receiver; no new hole, part or barrel is
authorized. All whole-board DRC/current/Kelvin/field/Ground/pair/stack gates
still run. No existing current budget or guard is reduced.

The helper also searches complete positively typed Kelvin-input paths instead
of treating a two-edge diagnostic as the repair scope. A lead can extend past
an arbitrarily short first segment while preserving the actual source exit
and heading. Original-parent input-island ownership, clipped isolation and
saved departure observation receivers still decide every construction. Search
geometry is not permission to alter a Kelvin exit or cross an adjacent pin.
The current ATX comparator's whole-path shortcuts still refuse on real
neighbouring-pin clearance. A separate local search spends only the native
exit-to-corner room, leaving the original straight departure intact. That
bounded miter still needs the same independent input-island receiver and
fresh clipping; neither search can spend source-exit geometry or waive a
neighbouring pin. Refused whole-path shortcuts remain recorded as refusals.

Tests exercise opaque identities, four rotations, both copper faces, native
barrel contacts, immutable allocation/current budgets, saved mutants, and
false bbox/other-face hiding claims. Fixture loads are not new board budgets.

## Unequal-width power observation

The original material-equivalence observer requires equal trace widths. A
separate read-only power observer handles only literal unequal-width native
power joins with independently rederived existing current authority. Both
complete native junction caps must lie inside canonical authored outlines
and actual saved same-face, same-net fill. Outline-only, bounding-box and
opposite-face evidence is refused. This conservative pre-drill bound does
not fill a drill void. It says nothing about remote track-body coverage,
capacity or the inherited current debt. It cannot exempt an ordinary signal
corner. Better verification coverage is reported separately from copper
repairs, and no native copper is changed to improve an observer count.
