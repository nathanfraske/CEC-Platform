# Resumable current-path windows

The prior ten-second search could examine only 21 of 1,350 ATX ranked windows
before a local pass reported no received child. That was a bounded search
stop, not exhaustion of the native Source graph.

The new scheduler inventories every eligible two-to-eight-edge Source window
within the original 4,096-track / 8,192-window limits. It caches exact native
capsule membership in actual registered, filled, non-island Source keepers.
The common-keeper, unchanged Source span/process and canonical path enclosure
tests are necessary proposal filters only. They cannot admit a route.

Pages have a literal Source-family, code/helper and inventory binding. They
form a gap-free prefix; an empty first page is not a plateau. Independent
sweep receiving regenerates the entire inventory and replays every original
owner result not rejected by the necessary native filters. A changed Source
invalidates the cursor. A finite prefix is never called global exhaustion.

Every actual construction goes through the original full-current path owner,
native DRC and whole-parent gates. Multi-child batches replan from the actual
preceding received child. Overlapping cuts are skipped after replacement;
cached proposals are never transplanted onto another Source.

No current/width, clearances, pad/barrel, Ground sheet, component placement,
board outline or fabrication rule is relaxed.
