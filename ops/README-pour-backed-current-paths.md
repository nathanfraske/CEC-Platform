# Full-current paths under literal native pour

The original full-current path finisher correctly refuses ownership of a pour.
Consequently it cannot simplify even a short full-width zigzag completely
covered by an unchanged actual keeper. An ordinary signal-width shortcut or a
claimed zone current rating is not an acceptable fallback.

cec_pour_backed_current_path.py requires the existing complete current model,
literal fixed end ports and exact source track width/face/process. Every old and
new capsule must be enclosed by one registered, genuinely filled, non-island
native source keeper. That entire keeper and every other original object,
including all Ground sheets and contacts, stay literal. Actual copper is
unchanged, not replaced by an analytical/FEM slab. Contact kernels remain in
the new full-width tracks or in the identical original native keeper.

This does not credit zone/barrel ampacity. The new tracks still meet the actual
source-current width floor; the exact current authority, source-control
reservations, surviving native partitions and independent current-debt checks
must pass. No pad, via, process rule, budget, model, sidecar or placement changes.
Unknown/inherited electrical and manufacturing debt is not qualified.

The finite runner discovers native uniform source-series corridors and fairly
alternates net/face/series families. It retains the last received child and
stops when the next finite menu has no accepted improvement. Native-only
intermediate intake is not a full-board grade:

    PYTHONPATH=scripts:ops:build /usr/bin/python3 \
      build/root_run_pour_backed_current_pass_20261020.py \
      --source SAVED/board.kicad_pcb --grade EXACT/diagnostics.json --hint BOARD_ID \
      --maximum-cohorts 4 --maximum-candidates 8 --allow-locked-source \
      --reporting-build NATIVE_REPORTING_BUILD --out FRESH_WORK

Every final phase still needs source-exact saved reconstruction, uncapped native
DRC, full parent current/field/reference/pair/Ground/clipped-Kelvin checks,
dimensions and mating verification. Plots must distinguish native physical
copper from a diagnostic centerline overlay: shorter hidden tracks need not
change the copper image. Neither a simpler path nor zero opens grants release.
