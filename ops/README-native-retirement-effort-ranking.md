# Native retirement effort ranking

`cec_native_retirement_screen.screen` is a bounded in-memory native
connectivity counterfactual. It does not edit, own or authorize source cuts.
It ranks known geometry proposals as preserving, losing or unknown for
surviving native net components. Actual zones are included; unknown fills,
ambiguous IDs, unsupported scopes, inventory limits and deadlines return
unknown rather than pretending that a path is impossible.

The supply finishing sweep funds likely redundant paths before long essential
paths. Unknown and losing paths remain in the finite menu; the screen does
not admit anything. Every selected candidate still runs the unchanged full
load/actual-drill/partition/source-replay/current-debt/native-DRC and whole
board receivers. No thin branch, current-domain or shared-barrel exemption is
created. Original source bytes, current budgets and rules stay unchanged.

The default source work width remains 0.35 mm. An explicit ceiling up to 1 mm
uses the independent receiver's existing finite work-scope contract. It
permits discovery of already fully sized medium-current source paths; it
does not reduce their actual layer-specific current floor. The same literal
ceiling propagates through bounded source subpaths and causal tail/covered
closure, and the saved receiving parameters record it.

The saved candidate must improve the broad bend inventory AND remove actual
native copper before expensive current receiving is funded. The material
observation subtracts retained same-net copper, real substrate and every
actual bore when a positive removal is claimed. A lower primitive count
hidden inside an existing landing or pour is not physical polish. Surviving
offers repeat the independent current receiver and retain the exact saved
hash through subsequent native-craft/material observations and native DRC.

These are effort and rejection optimizations, not weaker acceptance gates.
Synthetic regressions cover frames, faces, unknown topology, essential cuts,
partial dead trees, explicit width bounds, retained material coverage, and
the obligation to fund all original receivers for a genuine improvement.
