# Literal original reference-sheet retention

An outer-layer reconstruction need not recompile untouched dedicated Ground
reference layers. Native refill can perturb distant polygon tessellation;
those differences must not be ignored by an exact preservation comparator.
This owner reconstructs the **literal original saved sheets** instead.

The original Source must be the same whole-transaction parent. Parts, pads,
artwork, fields, groups, stack, outline, factory profile and sidecars stay
exact. Every non-Ground obstacle on a reference layer must be unchanged;
only removal of existing foreign vias is permitted. No new/moved bore, inner
route, foreign zone, or altered Ground track/barrel can reuse a frozen fill.
Source authored Ground-zone intent is identical; each dedicated zone owns
one reference face. All original native polygon vertices, fracture bridges
and island flags are restored. No synthetic area, healing or tolerance is
accepted. Stale or forged proposals and all collateral saved changes refuse.

This phase does not authorize any preceding route change. Those transactions
are independently reconstructed first. The saved original Ground nodes and
every other incoming object must then match exactly. Incoming native graph
partitions are preserved, and independent native DRC, exact pair/reference
inclusion, current, field, Kelvin, Ground-return, label and stack gates still
run. Retention is not new capacity or positive electrical/EM/fab qualification.
