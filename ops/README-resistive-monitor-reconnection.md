# Positive resistive-monitor local reconnection

`cec_resistive_monitor_reconnection` is a bounded saved-board operator, not a
net-name, board, reference-designator or coordinate exception. The caller
provides the actual root and target UUIDs and literal proposed geometry. Both
planning and receiving independently reproduce the existing manufacturer/
selected-divider monitor proof and complete single-tap consumer allocation.

Only the proved exclusive ungrouped monitor strokes can be replaced. The new
outer-face route is shorter, preserves the actual root, uses the existing
positive monitor/process width, and has exact 0/45 strokes and no hard-90,
backtracking or self-crossing turns. A retained target must be allocated
copper or a native island barrel that actually contacts already sized
allocation copper. A bore is subtracted from the positive contact witness.

An old root pickup may be removed only under explicit caller permission and
the unchanged generated-pickup owner, after reconstruction proves that it
contacts exactly one outer face. No unused through via is left behind. The
native disappearance of an otherwise empty original generator group is
recorded explicitly; no unrelated group can be dropped. JSON manifests are
normalized and fully reconstructed after reload. SMD faces come from actual
layer membership, not the pad object's nominal primary layer.

The independent receiver replays exact source-minus-owned-cut-plus-native
route, including the factory-owned pickup and ground refill. It checks all
surviving native conductor partitions, actual drilled terminal graphs,
preexisting full-width allocated joins, current-debt object nonregression,
unchanged whole consumer and aggregate budgets, parts, settings, sidecars and
all other nodes. A saved route must be exactly the newly typed exclusive leaf;
redundant strokes hidden inside a landing are not silently accepted.

Manufacturer resistor-input bounds are not power-path current ratings. The
entire consumer allowance and aggregate rail ceiling remain unchanged.
Terminal/plating capacity, inrush, fault and thermal qualification are not
granted. Native DRC, clipped Kelvin, pair/reference, ground, field, mating and
release receiving remain mandatory. Historical wide monitor leaves exceeding
the existing native classifier's 0.35 mm source bound remain refused; this
operator does not raise that global bound.

Synthetic regression: `tests/test_resistive_monitor_reconnection.py` covers
arbitrary references and nets, all four right-angle rotations, both board
faces, with/without original root pickups, JSON roundtrips and adversarial
source/candidate/contract changes. Real-candidate receipts bind exact source,
candidate, runtime code and this separate operator's identity.
