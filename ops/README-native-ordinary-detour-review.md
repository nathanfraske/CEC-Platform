# Native ordinary-detour review and source locks

The read-only census derives eligible ordinary nets from the unchanged design
policy and native board. It classifies every ungrouped, straight source stroke
into maximal same-face, same-width endpoint chains, stopping at real pad/via
contacts, branches and process boundaries. Power, Ground, differential pairs,
sensitive scalar roles and opaque groups retain their existing owners.

Canonical shortcut proposals retain the actual boundary ports, source width
and native contacts. Every proposed full-width leg passes the existing native
foreign-copper, board-edge, track-rule and conservative field-search checks.
The 20 um lower-bound comparison is only a search-interest cutoff, never a
clearance, source-loss or route-admission tolerance. The default local window
is 16 strokes; the explicit extended census permits 31, still below the
unchanged ordinary receiver's 32-track default and the exact guide algebra's
32-point bound. A finite portfolio that finds no shortcut is not a global
optimality, necessity or no-path proof.

The slice constructor treats every census row as a hint. It rechecks against
the actual preceding child, uses exact explicitly selected locked-track UUIDs,
and delegates saved source-minus-cut-plus-new-copper/ground replay to the
original independent ordinary receiver. Each accepted stage additionally has
a fresh uncapped native producer, zero opens, no new native faults and no new
exposed hard turn or backtrack. Work is bounded to at most eight attempts per
slice. Whole-parent current, fields, clipped Kelvin, Ground returns, pairs,
matching, dimensions, markings and fabrication qualification remain separate.

Mixed lock flags are not a physical process difference. The metadata helper
`cec_lock_preserving_track_template.derive` first binds the actual in-memory
board to its saved source. All selected process fields must match except lock
strength. The replacement is locked if ANY original selected stroke was locked;
no source object changes, no lock weakens, and no cut or net-role permission is
granted by this helper. The existing ordinary receiver still rederives ownership.
Synthetic tests cover both faces, all lock combinations, stale/missing source,
width/face differences, mask, group and non-track refusal. There are no board,
reference, named-net or coordinate exceptions in either metadata decision.

The follow-up slice saves a structured failure stack for refused attempts.
Rejected children remain diagnostic artifacts; a failed proposal never replaces
the preceding positive candidate. The next pass must recensus that actual
candidate, not repeatedly replay a stale winning shortcut.

Before publication, independently rederive whole dedicated-Ground-sheet
inclusion and require all unchanged pair primitives to remain exact. Ordinary
connectivity, native DRC and sampled field checks alone cannot waive a tiny
reference-fill loss. If the original reference-face obstacles, parts, Ground
tracks, groups, rules and zone intent remain exact, the existing separately
received literal-reference-sheet retention stage may preserve the original
polygons. It is ineligible if new/moved reference-face obstacles or bores exist.
The reference-bound publisher reruns the actual native inclusion predicate;
neither a saved success flag nor a bound negative report can publish a loss.
