# Added Ground bores and existing pair reference

The existing no-new-bore reference-sheet lemma remains unchanged. It is not
applicable to a new ground-return via, even when the via is otherwise legal.

The separate `cec_added_ground_bore_reference` receiver proves a narrower
physical statement for one to eight purely additive Ground through bores.
Every original footprint, conductor, surviving drill, stack and sidecar stays
literal. An independent native additive replay must reproduce the actual saved
Ground fills and local-rule membership. Its lease is at most ten seconds.

A separate at-most-ten-second geometry phase examines both sources of real
reference loss: every missing native filled-polygon region and every new
circular drill aperture. Each must be disjoint from every actual Source pair
track, land and barrel on every face, with the existing Source pair clearance
applied conservatively. This uses integer native polygons, not midpoint
samples, area tolerances, plot pixels, repaired geometry or artificial copper.
An original invalid pair/profile role remains invalid and unqualified.

It is deliberately not claimed that all global physical Ground metal is
unchanged: drilling removes real material. Source Ground fill may also change
where native refill recomputes the added via contact. Such changes are disclosed
and cannot touch the protected pair projection. Native fill replay and exact
Source reconstruction prevent unrelated Ground edits being hidden in that
statement. Complete known-Ground return, native partition, current, field,
Kelvin, DRC, stack and fabrication receiving remain independent requirements.

The private review and publication adapters select this exact proof for the
added-bore operation; they do not weaken or repurpose the old no-new-bore
receiver. Neither receiver grants electrical, impedance, current, thermal,
barrel, reference or production qualification.
