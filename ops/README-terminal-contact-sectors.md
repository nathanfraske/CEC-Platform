# Pour-only contacts during terminal contour finishing

The trace/via envelope is not the complete power network. A real capacitor or
other port may be fed only by incumbent filled copper. The optional
`cec_terminal_contact_sector.py` owner extends the existing terminal-shadow
transaction with finite original-source sectors, anchored at existing plated
terminals. It does not invent a new trace, budget or current-sharing premise.

Every old surviving contact stays literal. A source-bound native erosion at
the unchanged actual source-current face floor additionally preserves each
positive port partition; keeping contact pixels while pinching the feed is
rejected. This is a conservative geometric width/connectivity witness, not
thermal, zone/barrel ampacity, impedance, full Kelvin or fabrication rating.
Unknowns are not promoted to qualification.

The authored owner cannot grow. Newly authored edges are literal cardinal/45;
an incumbent noncanonical subedge is allowed only as an exact original segment,
and is disclosed, not snapped or excused with an angle tolerance. A filled
contact already outside its old authored edge is preserved only as that exact
source-native fringe. Stronger same-net voids remain protected. Compiling this
one owned keeper never refills Ground or edits other conductors or markings.

The retained support gets an octilinear chord closure constrained to the literal
original authored owner. This prevents a trace-envelope union from carving
small scallops into previously straight bus edges. It cannot fill an original
reserved pocket. Full native width/contact checks and actual visual review
remain mandatory; failed pilot geometry is never selected just because its
electrical checks pass.

Use the bounded pass from the repository root with a fresh output directory:

```sh
PYTHONPATH=scripts:ops:build /usr/bin/python3 \
  build/root_run_terminal_contact_sector_pass_20261020.py \
  --source SAVED/board.kicad_pcb --grade EXACT/diagnostics.json --hint BOARD_ID \
  --maximum-cohorts 2 --max-trials 8 --allow-locked-source \
  --reporting-build NATIVE_REPORTING_BUILD --out FRESH_WORK
```

The finite portfolio retains the last genuinely received child. Every final
`terminal_contact_sector` phase still needs the original whole-parent current,
native partition, clipped Kelvin, field, Ground return, uncapped native DRC,
metadata, dimension and mating checks. Inspect the actual saved six-layer and
local before/after native copper before publishing a diagnostic. A cleaner
local contour is not an all-contours-clean or fabrication-release certificate.
