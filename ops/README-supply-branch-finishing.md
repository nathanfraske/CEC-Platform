# Bounded obsolete supply-path finishing

`cec_redundant_supply_branch_sweep.py` is an optional agent-construction tool,
not a production selector or fabrication release. It contains no board,
reference-designator, net-name or coordinate special cases. It discovers
small endpoint paths touching native bend findings and uses the
existing component-budget supply catalog; it never invents branch loads.

Only already full-load-rated plain outer-layer source tracks are eligible.
The search is bounded to 32 requests, eight tracks per cut and five native
tail-closure trials. Default source-cut receiving has a ten-second work
lease. `--cut-receive-timeout-s` explicitly permits up to the unchanged
receiver's existing thirty-second bound; native DRC remains ten seconds.
Shell commands return control after ten seconds while longer jobs continue.

The worker now also proposes bounded subpaths, rather than forcing an
essential continuation into every maximal-path cut. Both menus share a
128-window bound; each seed and extension must fit the eight-track bound.
This is discovery only: every complete proposed cut still needs the same
original-parent native, full-load, boundary and saved-DRC proof. Use
`--whole-paths-only` to retain the older discovery menu for comparison.

The unchanged `cec_redundant_rated_branch.receive` must prove each entire cut
against its original source: actual native conductor partitions, drilled
terminals, full-load planar terminal joins, source boundaries, exact saved
subtract/refill, unchanged current contracts and whole-board current debt.
No new copper, barrel, part motion, factory rule or width reduction is allowed.

If saved native DRC exposes a dangling tail, only the reported UUID of an
eligible original same-net/face plain track may enlarge the next cut. Each
retry is rebuilt from the original source, not the failing intermediate.
Every current and topology check is repeated. Other warnings, opens,
unsupported owners or exhausted bounds reject the proposal; warnings are
never suppressed. A winner must reduce observed bends and remove positively
proved actual copper, not merely change duplicate representation. Material
gain is clipped to actual board substrate and excludes all native drill
bores, including netless holes; raw lands in voids are not copper gain.

Stage success is still private. Independently receive the full finishing
chain only after default craft nonregression as well as the broad bend score.
A cut that exposes a new covered backtrack may propose retirement of its
shorter original stroke only with exact full-capsule coverage by an unchanged
retained Source peer. The entire enlarged original-parent cut is rebuilt and
received again. Other new craft issues are refused, not suppressed.

The exact saved bend-improvement gate runs before expensive independent
current receiving. This only rejects the same non-improving shapes earlier;
it does not accept a shape, change the finite menus, skip current/native
receiving for any survivor, or loosen the causal-retry bounds. The saved hash
is checked again after independent receiving. Each refused trial records
whether that heavier work was run, so wasted work is observable.

Independently receive the full finishing
chain against its original parent, run native DRC, absolute clipped Kelvin,
all known ground returns, field/pair/craft/contour checks, matched-stack and
original-dimension checks, inspect saved layer plots, and bind exact tool,
source and candidate hashes before updating a review pointer. Existing fab
and electrical qualification debt remains debt.
