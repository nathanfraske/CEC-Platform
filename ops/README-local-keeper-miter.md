# Local current-owned keeper miters

The optional `cec_local_keeper_miter.py` constructor addresses a discovery gap:
track-only finishing skips a trace completely covered by a power keeper, even
when the keeper still contains the same sharp corner. Rebuilding the trace
alone does not change the manufactured copper. Rebuilding an entire historical
pour from guessed old generator settings is not acceptable either.

This operator requires two literal, same-width, ungrouped cardinal source
tracks, a complete existing current contract, explicit lock permission and one
actual filled registered keeper. The old tracks must already carry their full
unchanged current floor. A finite local window may contain no other same-net
terminal or branch and no courtyard/keeper window needing separate ownership.
The old local pour must be contained in a bounded outward envelope of those
actual tracks. The 4 micrometre envelope is an ownership restriction, not an
electrical width allowance or a fabrication-clearance tolerance.

It replaces the two tracks with a full-width 45-degree miter and updates only
the matching local keeper window. Every remote native region/window and all
source settings remain exact. Local new track capsules must be enclosed;
outside the window every replacement tail must be an exact subset of the old
straight capsules. No new pad, barrel, part motion, budget, source layer or
parallel-current sharing is authorized. Existing source contacts, whole native
partitions and original full-width boundaries must survive.

Plan/construct/receive is a saved, source-hash and constructor-hash-bound
transaction. The independent receiver reconstructs the entire expected board,
checks its saved family and current model, and requires positive actual copper
removal and fewer bend findings. Native DRC, full current debt, absolute clipped
Kelvin, all known Ground returns, field/pair/craft/contour, matched-stack and
original-size checks still have to pass before a diagnostic frontier advances.
Neither construction success nor zero opens constitutes fabrication release.
