# Isolated Kelvin-input path finishing

This is not ordinary-net permission for a force/sense net. Manufacturer
lineage, literal native source/sense lands, a complete source-bound positive
clipped replay and the actual same-face input component identify the scope.
Each clipped fragment of every selected thin track must contact only that
input component in both native envelopes. All real bores and saved net fills
are included. Candidate input-island pad membership remains identical.

Only a shorter fixed-port 0/45 path with unchanged width, face, lock and
process is supported. No pad, part, barrel, force conductor, project rule,
current load or current budget is synthesized or relaxed. Old native side
contacts, boundary tangents, surviving components and actual terminals are
received separately. Exact whole-source reconstruction and fresh independent
current debt remain hard gates, alongside native custom-rule DRC, fields,
ground returns, pairs/references, stack and all release qualifications.

Newly enclosed same-net voids are refused. Actual source and candidate native
clipped replays must positively readmit every affected leg. A generic contour
comparison cannot silently treat a changed Kelvin departure identity as the
old track. This stage therefore retains an explicit identity/end/BFS ledger
only for its exact retired/added departure tracks: source exit, projection,
heading, target set, input identity, record fields and departure counts remain
exact. Both recorded endpoints must match the actual native track; BFS paths
must consist of real items and terminate at the same input. All remaining
physical evidence still passes the original strict comparator. Raw refusals
are retained in the report. This is not an electrical or full-Kelvin rating.

Native integer component assignment avoids a GEOS boundary-predicate trap
observed during discovery (covers false with an empty difference). There is
no numeric healing, area epsilon, guessed load, or centerline-only deletion.

The whole-board wrapper currently supports one such transaction per receiving
invocation, or a literal unchanged family. It refuses mixed/repeated chains
instead of applying a departure ledger to another edit implicitly. General
multi-phase composition remains a separate explicit integration task.
