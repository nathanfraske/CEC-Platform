# Source-owned native consumer-feed reanchoring

`cec_native_consumer_feed_reanchor.py` constructs a bounded transaction for an
already positively typed consumer allocation. It has no board, reference, net
name, or coordinate exceptions. The caller selects native UUIDs; selection is
not authority. The existing independent consumer-feed receiver reconstructs the
saved delta and the whole-parent current-debt receiver must also succeed.

The old feed must be an ungrouped outer-layer chain. Its removal must expose one
complete exclusive input island, including only supported local bypass parts
and independently typed monitor loads. The allocation and aggregate budget,
margin semantics, packages, barrels, parts and other native partitions remain
unchanged. Newly acquired exclusive input conductors may only widen to their
exact existing layer floor. Already-owned control leaves are not blanket-widened.

A retained terminal can launch the new canonical 0/45-degree path. The destination
is an unchanged native pad or via on the same face. Shared same-net copper outside
that terminal's actual aperture is a routing obstacle, not an implicit extra tap.
Foreign copper, board edges and source identity remain hard constraints. A native
post-save producer must independently check the result before review admission.
Retained terminal rays constrain actual search edges: a final approach may not
create an exposed acute or covered two-stroke backtrack against an existing
lead. Actual same-net pad copper may absorb an angled join, but never excuses
a covered collinear overlap. Near aliases require native shape contact; no
snapping is performed. The unchanged independent craft audit remains mandatory.

The runtime selector now recognizes the existing Samsung CL21A106KAYNNNE 10 uF
0805 input bulk capacitor only on a positively modeled TPS2121 pass-through input.
It retains the selected 100 nF bypass behavior. Wrong package, MPN, manufacturer,
value, population, pin topology, extra load or cross-rail connection still fails.
This models topology, not a new continuous leakage, inrush, fault, thermal or
capacitor derating qualification. No numeric current budget is reduced or invented.

Synthetic regression rotates and flips opaque fixtures and attempts forged
packages, loads, poses, widths, tap ownership, sidecars and saved deltas. Actual
board replay additionally requires native DRC, complete clipped Kelvin evidence,
physical ground preservation, pair/reference retention, mating, dimensional,
silkscreen and immutable-control checks. These are review candidates, not an
electrical, barrel-current, thermal or fabrication release.
