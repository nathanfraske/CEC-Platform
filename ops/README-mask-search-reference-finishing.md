# Mask-aware reference seat search

The existing chart-first, opposite-face courtyard owner is retained exactly.
Its native obstacle provider now also includes actual same-face mask artwork
while trying seats. A late mask filter can reject a group's first seat without
ever exploring a valid alternate; mask-aware search prevents that avoidable
false dead end. It does not guarantee a seat exists.

The extension uses a private module namespace, not a process-global patch.
Plans bind both original and extension code plus the actual mask provider.
Original reference ownership, glyph/stroke dimensions, pad/drill openings,
substrate, native second-save reconstruction and all electrical/manufacturing
rules remain unchanged. The mask preflight is still independently replayed,
and a complete native DRC is still mandatory before a child can advance.

Rear outlines are footprint children at their actual projected coordinates.
Their references read normally from the back. A successful label operation
cannot move a part, change copper, alter a BOM item, or authorize fabrication.
