`scripts/cec_thermal2d.py` (≈2161 lines, self-tests A–K passing, dated 2026-06-19) IS the fine-density GPU-capable field electrothermal solver. The owner built it and remembers it; I forgot it existed, built an analytic-only narrative on `cec_synth_pipeline.electrothermal_solve`, and that lumped per-net model HID a real 181 °C shredded-pour failure (foreign traces routed through the high-current pours). **Before any thermal check, gate, or claim that a board is fab-ready, reach for cec_thermal2d FIRST.**

What it does (the physics the analytic lacks): rasterizes real pcbnew copper to a uniform grid (grid_mm 0.3 coarse → 0.1/0.05 fine), one electrical node per copper cell per std-layer (F.Cu/In1/In2/B.Cu); same-layer neighbors linked by sheet resistance; **layers couple ONLY through real PCB_VIA barrels** (`_barrel_segment_R`) — so a sparse via field runs the fed layer hot (self-test B: 1.95× vs a stitched plane); tracks rasterized with EFFECTIVE-WIDTH sheet conductance so a 0.2 mm trace stays grid-independent (`_rasterize_tracks`, self-test F within 1.2%) — the shredded-neck resolver; shunts = lumped I²R sources; connector pads = area-injection Neumann BCs. It RESOLVES the LOCAL current+temperature field, so it catches the via-fusing + shredded-neck hotspots the analytic averages away (self-test H: via-barrel hotspot lands at the physical via at 186.6 °C). GPU/AMG path is already coded in `_spd_solve` (cupy + pyamg).
