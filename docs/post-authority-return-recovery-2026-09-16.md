## Shared implementation

`cec_post_authority_recovery` permits this recovery only when pad, courtyard
and constraint gates pass, decoupling is the only failed craft checker, and
the report contains a structured exhausted native ground-return search.
Integrity errors and unknown failed checkers are not repair permissions.

The helper uses the existing frozen-placement domain and atomic frozen-craft
commit. It then requires bound authority, exact power admission and all fresh
physical gates. Failure or exception restores the entire private artifact
family; it cannot replan or weaken frozen power. Acceptance returns to the
existing full priority measurement and ordered candidate comparison—it does
not grant routing or release admission.

Power-replan dispatch permits **one recovery call per operation** by default,
shared across its candidates, rather than an open-ended retry per candidate.
Policy parameters are `post_authority_return_recovery_calls` (0–4) and
`post_authority_return_recovery_trials` (integer 1–64, default 16). Each call
has exactly one round and epoch and inherits the existing enclosing deadline.
Every attempt or deferred call is recorded. There is no board/refdes/coordinate
selector; the new module is included in the static generalization inventory.
