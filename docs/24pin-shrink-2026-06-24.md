# 24-pin ATX module — shrink study: straight-through vs 90° (rev2)

_2026-06-24. Overnight floor-hunt requested by owner: "how small can the loop get the 24-pin connector",
comparing the two connector revisions' local minima._ Dashboard: http://localhost:8095 (run-dir `build/24pin-rev2-shrink`).

## Headline — the 90° revision is 21% smaller

| Revision | Board | Size | Area | Route (passes 8 / opt 12) |
|---|---|---|---|---|
| **straight-through** (J3 left + J4 right, both vertical) | `modules/atx-24pin/24pin-module.kicad_pcb` | 110.2 × 75.7 mm | **8342 mm²** | kelvin✓ diffpair✓ unconn 0 / clips 164 / drc 3 |
| **90° (rev2)** (J3 left vertical + J4 bottom horizontal — the L) | `modules/atx-24pin-rev2/24pin-module.kicad_pcb` | 83.1 × 79.2 mm | **6576 mm²** | kelvin✓ diffpair✓ unconn 0 / clips 208 / drc 0 |

**The 90° (rev2) board is 21% smaller (6576 vs 8342 mm²)** and routes clean. The owner's hypothesis — rotating the
output connector lets the board pack tighter — is **confirmed at baseline**. (The L tucks the two 62.6 mm-long
24-pin headers into perpendicular edges instead of side-by-side, freeing the middle for the logic.)

## Both boards are at their rigid-shrink floor (0%)

The shrink-sweep (rigid narrow + smart re-pack of foreign parts, connectors/shunts fixed, route+score each step,
keep the smallest still-valid: kelvin held / unconn ≤ start / drc+clips within tol) found **0% on both**:
- **straight-through**: every step hits ONE unresolvable courtyard overlap — it is **connector-perimeter-bound**
  (the two 24-pin headers + RJ-45 + USB-C tile the edges; board is 86%+ footprint-filled). Floor = the current size.
- **90° (rev2)**: every step hits 16–20 overlaps — **densely part-packed**. The 3 big parts (ESP U1 45.5×39, J3,
  J4) are **75% of the 6576 mm²**, so there is almost no placement slack left to rigidly compress.

clip-tol was set generous (120) and repack=smart (try hardest) per the owner's "everything possible to save space"
— still 0% rigid. The size is **part-courtyard-bound**, which also means **pour-width reduction does NOT shrink the
outline** (parts collide before the pours do); the pour/thermal lever is orthogonal to size here.

## The real remaining lever — ~1270 mm² of dead space in U1's stale keepout (≈19%)

rev2's ESP **U1 carries a STALE embedded courtyard of 45.5 × 35.3 mm**, but the library footprint
(`cec-RF_Module:ESP32-S2-MINI-1_NoAntKeepout`) is already trimmed to **16 × 21.2 mm** (the 24-pin is wired-only —
no antenna keepout needed). So the board currently RESERVES ~**1270 mm²** of empty space around U1 (baseline
drc=0 → nothing sits in it). "Update U1 from Library" reclaims it; a **from-scratch re-placement that packs the
logic into that freed zone** could reach ~5300 mm² — **another ~17–19% on top of the 21%** (total ~36% vs straight).

The rigid shrink-sweep CANNOT capture this (it translates the far half rigidly; it does not re-place into U1's
freed pocket — and its overlap model already used the trimmed 16×21, so it sees no wall there). Capturing it needs
a **from-scratch re-place with the connectors pinned at the L positions** — delicate, because a blind re-place
strands the 4 rail shunts off the J3→J4 path and breaks kelvin (verified: 3 blind attempts on the straight board
all broke kelvin / left 9–17 nets unrouted). So this is best done **with render review**, not a blind overnight
auto-run.

## Recommended next steps (owner to greenlight)
1. **Reclaim the U1 dead space**: Update U1 from Library on rev2 (courtyard 45×35 → 16×21, lets GND fill under it),
   then a guided re-placement packing the logic into the freed pocket → target ~5300–5500 mm² (~36% vs straight).
2. **Pour/via reduction under a thermal gate** (owner-authorized): wire the 2.5D thermal solver into the loop's
   validity gate so the worker agents can narrow the rail pours / drop redundant stitching vias and KEEP only
   states that still pass dT ≤ 30 over the stackup. Note: this trims COPPER mass, not board OUTLINE (the 24-pin is
   part-bound) — it's a current-margin/cost lever, valuable but separate from the size floor.
