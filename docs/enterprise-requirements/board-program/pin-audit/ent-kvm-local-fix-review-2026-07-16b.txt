DEFERRED (documented, not silently skipped -- see FOLLOWUPS.md for the
dated bullet):

  M2_MKEY_A_M3C / M2_MKEY_B_M3C (J4/J5, sheet 09-m2-module) -- 67-pin
    symbols each, MPN on the schematic is HYCW23M-05NGFF-670B (HOAUC,
    "M2-MKEY-75P-A"/"-B" per the Value field). NO live LCSC listing found
    for this exact MPN this session (only a same-family sibling,

    multiple real keying/notch variants (A/B/E/M-key, differing pin
    subsets), so pulling a similarly-named but NOT-verified-identical
    footprint risks a real mis-keyed/wrong-pinout part, worse than leaving
    the gap open. This accounts for the BULK of the 45 high + 63 medium
    findings on this library (mostly TX-direction and GPIO-multi-function
    passive-vs-output/bidirectional calls across the two 67-pin symbols) --
    deliberately left alongside the footprint gap rather than fixed in
    isolation, since a correct pin-type pass and a correct footprint pass
    for a connector this large are naturally one piece of work once a
    verified real M.2 socket MPN is in hand.

  LT6911_FUNC (U11, sheet 10-hdmi-capture) -- the schematic's own MPN field
