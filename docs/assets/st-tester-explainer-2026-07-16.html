How the PSU Tester works

A guide for people fluent in computers, allergic to electronics. One idea to hold on to: testing a power supply means consuming its power on purpose, in precise amounts, while independent instruments watch it struggle.

The cast, in computing terms

Switched resistor banks

= worker pools you scale in fixed increments

A resistor is a component that consumes power and makes heat — nothing else. We group them in binary-sized packs (1, 2, 4, 8, 16 units). Turning packs on and off is literally setting load in binary: bit flags for amps. Coarse, instant, indestructible.

The vernier (analog throttle)

= the continuously-variable clock slider

Between the fixed steps you need a smooth dial. A special transistor acts like an infinitely-adjustable valve for current, closed-loop controlled: ask for 3.7 A and it holds exactly 3.7 A. Banks give you the big numbers; the vernier gives you the decimals and the smooth ramps.

SCP crowbar

= the chaos monkey

A deliberate, instrumented short circuit — the worst thing that can happen to a PSU, done on purpose in a controlled way to prove the PSU's own circuit-breaker reacts. Like yanking a power cord to test failover, except timed to the microsecond and repeatable.

Trip-watch comparators

= hardware interrupts, not polling

Chips that fire the instant current crosses a threshold. The slow measurement path samples at ~1 kHz — polling. These are the interrupt lines: they never miss the exact microsecond the PSU's protection tripped.

Measurement modules

= the observability agents (APM for electricity)

Each PSU cable type gets an inline meter it passes through — click-in modules with lab-grade (±1%) sensing. Separation of duties: the load plane is deliberately imprecise muscle; the modules are the calibrated source of record. Load generator vs metrics agent — never the same box.

The Hub

= the top-of-rack switch

Modules uplink to it over ordinary RJ-45 cables; it aggregates everything onto one USB uplink to the PC. In the tester it docks onto a backplane connector — power and data in one blade-style connection, zero cables to route.

CAN bus + CEC_MARK

= message bus + PTP clock sync

Every device sits on one shared bus and stamps events on a shared clock, aligned to a few microseconds. That's what makes "the 12 V rail dipped 40 µs after we stepped the load" a provable statement instead of two logs you're squinting at.

Orchestrator (the MCU)

= the CI runner

Test profiles are step lists — declarative, like pipeline YAML. The little computer executes them deterministically: set load, hold, step, measure, next. It also presses the PSU's "power button" (a control wire called PS_ON#) and stopwatch-times the PSU's "ready flag" (PWR_OK) — the boot-time handshake every PSU must perform to spec.

The safety rail (de-gate)

= a hardware dead-man switch

One wire that every load stage must actively hold to stay on. Overheat, dead fan, watchdog bite, even an unplugged internal cable — the wire releases and all load drops to zero physically, no software in the loop. Default state is OFF; the machine must continuously earn the right to run.

POST + cross-calibration

= boot self-test + auto-tuning against a reference

Before every run the tester self-checks. Then the neat trick: the calibrated modules re-measure the tester's own coarse sensors and correct them — the reference standard ships inside every station, so there's no annual "send it away for calibration" ritual.

Displays

= the dashboards

A main status face (total watts, test progress, pass/fail) plus a small live meter at every module bay — volts, amps, watts for that cable, right where the cable is. An empty bay just shows the logo.

USB-C self-power

= never run the harness on the server under test

The tester powers its own brains from a USB-C wall charger — never from the PSU being tested. When the test deliberately kills the PSU (short-circuit test, shutdown timing), the instruments and their data are unaffected.

The one-sentence version: the tester is a scriptable machine for eating a power supply's output in precise, timed bites, while independent calibrated meters record how gracefully the PSU copes — and a hardware dead-man line guarantees that "off" is always one broken wire away.
